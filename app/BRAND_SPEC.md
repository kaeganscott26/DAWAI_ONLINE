# Brand Spec (V2 Test Build)

## Theme Canon
Two locked themes only:
- `Dark Side`
- `Light Side`

## Light Side Constraint
- `Light Side` must be tinted/lifted.
- No pure white (`#FFFFFF`) for panel/window/surface tokens.

## Plugin UI Constraint
- Plugin visual style must not change across app themes.
- Plugin GUIs should remain premium hardware-inspired in both themes.

## Voice And Presentation
- No external DAW naming leakage in user-facing text.
- Product visual direction: premium space/neon with professional readability.

## Tokenization
- Theme values must be centralized (no uncontrolled one-off hardcoded panel/window colors in new work).
- Canonical theme tokens live in `config/theme_tokens.json`.
